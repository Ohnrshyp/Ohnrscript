# Ohnrscript Language Support

Welcome to the official VS Code extension for the **Ohnrscript** programming language, developed by **Ohnrshyp**.

This extension provides premium syntax highlighting and core language support to make authoring zero-allocation, bare-metal systems a beautiful and productive experience.

---

## Features

### Intelligent Syntax Highlighting
Ohnrscript features dynamic syntax highlighting perfectly synced with the `.ohn` compiler's dual-target pipelines, ensuring that LLVM IR and V8 structural boundaries are accurately represented in your editor.

### Zero-Allocation Semantics
Visual feedback for Ohnrscript's strict `i32` architecture, Data-Oriented Design (DOD) arena allocations, and bit-packed math engine semantics.

---

## Getting Started

1. Create a new file with the `.ohn` extension.
2. Start writing bare-metal, web-native syntax.
3. For documentation and language reference, visit the official [Ohnrshyp Developer Portal](https://ohnrshyp.com).

## Requirements

This extension requires VS Code version `1.80.0` or higher.

## Telemetry
This extension does not collect any telemetry data.
